# Fantabrawl v2

Demo iniziale del sito.

## Pubblicazione GitHub Pages
1. Carica tutti i file di questa cartella nella root della repository `Fantabrawl-v2`.
2. Apri **Settings → Pages**.
3. In **Build and deployment**, scegli **Deploy from a branch**.
4. Seleziona `main` e `/ (root)`, poi premi **Save**.
5. Attendi la pubblicazione GitHub Pages.

## Stato
Questa versione è una demo locale: i dati sono salvati nel browser con localStorage.
Non è ancora collegata a Firebase e non offre account condivisi o controlli Admin sicuri.
Prima del lancio pubblico saranno implementati backend e regole di sicurezza.
